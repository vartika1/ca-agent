# Interview guide — the complete question set

The skill's guiding rule is **detect, don't ask**: most facts come from the
taxpayer's AIS, prior return, Form 16, and mailbox — NOT from questions. This
guide lists the ONLY questions to ever ask, when, and why. Everything not
here should be self-served. Ask as structured, tappable questions (options +
"other"), one topic at a time, each with a one-line "why".

## Stage 1 — before the harvest (1 light question)

**Q1. Residential status.** "Were you in India the whole year, or abroad at
any point?" → In India all year = ROR, move on. Only if abroad, unfold the
day-count questions (days in India this year; days across prior 4 years;
citizenship). *Why: decides which income India taxes and whether foreign-asset
reporting applies.*

## Stage 2 — after the harvest (ask ONLY what data couldn't answer)

Detect first from AIS trails / prior return / Form 16 / mailbox. Ask these
only where detection is impossible or a value is genuinely user-held:

**Q2. Foreign assets (mandatory, once, for every resident).** "Did you hold
ANYTHING outside India at any point in the calendar year — foreign stocks,
employer RSUs/ESPP, foreign bank/broker account, crypto on a foreign
exchange?" *Why: foreign platforms don't report to India; a Schedule FA miss
carries Black Money Act penalties. Try to pre-resolve from prior return +
stock-plan emails first; ask to confirm.*

**Q3. Broker/platform list (only if the depository wasn't enumerated).** "List
EVERY app/broker where you've bought or sold shares this year — most people
have 2-3 (Zerodha, Groww, Upstox, INDmoney...)." *Why: plural framing; one
missed broker = under-reported gains. Prefer CDSL/NSDL enumeration over asking.*

**Q4. Crypto disposals (if any crypto platform detected).** "Did you SELL or
swap any crypto this year (buying/holding doesn't count)?" *Why: only disposals
are taxed (flat 30%); needs the exchange tax report if yes.*

**Q5. Property use (only if AIS/prior return shows an owned property).**
"Is it self-occupied/family-used, rented out, or vacant?" + if rented, annual
rent. *Why: rent is taxable income; interest deductibility differs. Often
answered by the prior return's Schedule HP — check first.*

**Q6. Rent paid (only if HRA is in the salary structure or a job-switch gap
exists).** "Did you pay rent, and how much per month, for [period]?" *Why: HRA
for a period the employer didn't process is still claimable at filing; can flip
the regime. The rent AMOUNT is user-held (or in bank statements).*

**Q7. Gifts (one light confirm).** "Any gift over ₹50,000 from a non-relative
this year?" *Why: undetectable if informal, but taxable. Skip if AIS shows no
large unexplained credits and probability is low — one confirm, not a probe.*

**Q8. Old-regime deductions (only when the regime margin is not decisive).**
Health insurance you paid yourself (80D); donations with receipts (80G) —
HUNT the mailbox for "donation receipt" before asking. *Why: these can flip a
thin regime margin; check them before declaring any regime verdict (see the
regime full-check rule).*

## Never ask (self-serve or drop with a stated basis)

- Date of birth, age, address, bank accounts → e-Filing profile.
- What income they had → AIS.
- Which mutual-fund apps → MF Central covers all.
- Prior-year regime / carried losses → prior return JSON.
- Minor-child clubbing → only if a signal appears (a minor's account surfaces).
- EPF/PPF/NPS contribution amounts → Form 16 (and irrelevant in new regime).

## The one rule that overrides brevity

Before declaring the REGIME verdict final, every old-regime flip-factor (HRA
per period, 80C/EPF, NPS, 80D, 80G, home-loan interest, professional tax) must
be resolved to a value — never skipped because the margin "looks wide". Checking
is exhaustive; asking is minimal.
